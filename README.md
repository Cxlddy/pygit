# PYGIT
- um projeto de sistema de versionamento e armazenamento de repositórios 100% feito com python, inspirado no git

## Tecnologias utilizadas:
- Python
- Hash SHA-1

## Comandos:
- pygit init (inicializa o repositório)
- pygit add [arquivo que deseja adicionar] ou [.] para adicionar o projeto todo
- pygit commit [mensagem da commit]
- pygit status (semelhante ao status do git)
- pygit log (mostra o histórico de commits)
- pygit show (mostra uma commit em específico)


## Como baixar e Rodar:

- Clone o repositório em uma pasta
- Rode no terminal dentro da pasta pygit: ''' pip install -e .'''
- Se divirta!
